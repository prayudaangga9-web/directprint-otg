# DirectPrint OTG

Aplikasi cetak Android ringan (tanpa iklan, tanpa izin internet) untuk cetak PDF & Gambar lewat USB OTG (IPP-over-USB / Raw USB) atau Layanan Cetak Android/Canon.

## Build APK Otomatis (GitHub Actions)
1. Upload seluruh isi proyek ini ke repositori GitHub.
2. Buka tab **Actions** -> pilih **Build DirectPrint APK** -> klik **Run workflow** (atau otomatis jalan saat push).
3. Tunggu ±2 menit, lalu download file APK di bagian **Artifacts -> DirectPrint-OTG-APK**.
